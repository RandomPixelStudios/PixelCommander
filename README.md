# PixelCommander

PixelCommander is a dual-pane file manager for Linux,
written in Python.

## Features

- Dual-pane file management
- Tabbed directories
- File copying, moving and deletion
- Keyboard shortcuts
- Custom icons and interface
- Linux support

## Platform

Currently developed for Linux.

## Status

Actively developed.
